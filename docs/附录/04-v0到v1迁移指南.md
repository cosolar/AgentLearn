# 附录 D · 从 LangChain v0.x 迁移到 v1

> 📅 更新至 2026-10 · 技术栈基线见 [教程大纲](../教程大纲.md)

面向"手上有旧代码"的读者。目标：**用最小改动把 v0.x 项目迁到 v1**，并理解为什么要这么改。

> 📚 配套阅读：[3.1 LangChain v1 核心组件](../03-LangChain实战/01-LangChain核心组件.md)（v1 架构全景）· [附录 B · 速查卡](./02-速查卡.md)（新写法速查）

---

## 一、为什么要迁移：v1 的三个核心变化

| # | 变化 | 说明 | 影响 |
|:-:|:-----|:-----|:-----|
| 1 | **`create_agent` 成为唯一 Agent 入口** | 取代 `AgentExecutor` 与 `langgraph.prebuilt.create_react_agent`；Agent 循环、持久化、流式、HITL 全部内置 | 旧执行器相关代码（`AgentExecutor`、`max_iterations`、`return_intermediate_steps`）整体重写 |
| 2 | **Middleware（中间件）成为控制面** | 压缩、审批、脱敏、限额、工具错误拦截都通过 `middleware=[...]` 声明式插入 | 原本靠"手动包一层"实现的横切逻辑，改为标准中间件 |
| 3 | **标准内容块（content blocks）** | 通过 `content_blocks` 跨厂商统一访问推理轨迹、引用、内置工具调用 | 不再依赖 `.content` 字符串 + 手工解析 |

此外还有三处**命名空间与生态**变化：

- `langchain` 收窄为"Agent 核心构建块"，旧功能（chains / retrievers / hub / memory）迁往 `langchain-classic`；
- `langchain_community.vectorstores` 被**拆分**，Chroma 等迁到独立包（`langchain-chroma`）；
- 追踪环境变量前缀由 `LANGCHAIN_*` 改为 **`LANGSMITH_*`**。

> 🎯 **一句话**：v1 把"Agent 该怎么跑"从**你手写的执行器**收回到**框架标准入口**，把"横切关注点"从**散落的包装代码**收拢到**中间件**。

## 二、大对照表：旧写法 → 新写法

> ⚠️ "旧写法"仅作对照，**不要在新项目中继续使用**。左侧代码可能在 v1 中直接 ImportError。

| # | 主题 | 旧写法（v0.x） | 新写法（v1） | 备注 |
|:-:|:-----|:---------------|:-------------|:-----|
| 1 | Agent 创建 | `create_tool_calling_agent(llm, tools, prompt)` | `create_agent(model, tools, system_prompt=...)` | v1 唯一入口 |
| 2 | ReAct Agent | `from langgraph.prebuilt import create_react_agent` | `from langchain.agents import create_agent` | 旧入口已弃用（函数仍在，带 `@deprecated` 告警） |
| 3 | Agent 执行器 | `AgentExecutor(agent=..., tools=..., verbose=True)` | 无需执行器，`create_agent` 内置循环 | 执行器整体消失 |
| 4 | 迭代上限 | `AgentExecutor(max_iterations=10)` | `ModelCallLimitMiddleware(max_calls=10)` | 改为中间件 |
| 5 | 中间步骤 | `return_intermediate_steps=True` | `agent.stream(..., stream_mode="updates")` | 用流式观察 |
| 6 | 短期记忆 | `ConversationBufferMemory()` | `checkpointer=InMemorySaver()` | 记忆交给 LangGraph |
| 7 | 窗口记忆 | `ConversationBufferWindowMemory(k=5)` | `SummarizationMiddleware(...)` / 裁剪历史 | 改为压缩策略 |
| 8 | 摘要记忆 | `ConversationSummaryMemory(llm=llm)` | `SummarizationMiddleware(model=...)` | 标准中间件 |
| 9 | 会话隔离 | `memory=` 单实例 | `config={"configurable": {"thread_id": ...}}` | 用 `thread_id` |
| 10 | 长期记忆 | 自行拼装 / `EntityMemory` | `store=...` + `runtime.store` | 跨会话记忆 |
| 11 | 提示词 | `ChatPromptTemplate` 塞进执行器 | `create_agent(system_prompt=...)` | Chain 场景模板仍可用 |
| 12 | 结构化输出（链） | `PydanticOutputParser` + `format_instructions` | `llm.with_structured_output(Schema)` | 链式场景 |
| 13 | 结构化输出（Agent） | 手工解析最后一条消息 | `response_format=Schema` → `result["structured_response"]` | 主循环内生成 |
| 14 | 模型初始化 | `ChatOpenAI(model=...)` 分散各处 | `init_chat_model(...)` 统一入口 | 一行切厂商 |
| 15 | 消息导入 | `from langchain_core.messages import ...` | `from langchain.messages import ...` | 两者等价，推荐短路径 |
| 16 | 工具导入 | `from langchain_core.tools import tool` | `from langchain.tools import tool` | 同上 |
| 17 | 文档类型 | `from langchain.schema import Document` | `from langchain_core.documents import Document` | 旧路径已移除 |
| 18 | 向量库 | `from langchain_community.vectorstores import Chroma` | `from langchain_chroma import Chroma` | 生态拆分 |
| 19 | 向量库持久化 | `vectorstore.persist()` | 构造时传 `persist_directory`，**写入即落盘** | `persist()` 已弃用 |
| 20 | 嵌入模型 | `from langchain_community.embeddings import OpenAIEmbeddings` | `from langchain_openai import OpenAIEmbeddings` / `init_embeddings` | 生态拆分 |
| 21 | 检索器 | `vectorstore.as_retriever()` | 同左（保留） | 兼容 |
| 22 | 消息内容 | `response.content`（str） | `response.content_blocks`（跨厂商统一） | 处理推理/引用更稳 |
| 23 | 人机协同 | 手写 `interrupt_before=["tools"]` | `interrupt()` + `Command(resume=...)` | 节点级中断 |
| 24 | 工具错误 | 每个工具裸 `try/except` | `@wrap_tool_call` 统一拦截 / `ToolException` | 中间件化 |
| 25 | 追踪环境变量 | `LANGCHAIN_TRACING_V2` / `LANGCHAIN_API_KEY` | `LANGSMITH_TRACING` / `LANGSMITH_API_KEY` | 前缀变更 |
| 26 | 回调追踪 | `callbacks=[...]` 手工挂 | LangSmith / OTel GenAI 自动接入 | 可观测性升级 |
| 27 | 包结构（1.2+） | `langgraph.prebuilt` 随 `langgraph` 一起装 | `langgraph.prebuilt` 由独立发行包 **`langgraph-prebuilt`** 提供 | **导入路径不变**；`--no-deps` 安装需手动补装 |

## 三、逐项迁移示例（before → after）

> 每个示例都是**完整可对照**的：左边旧写法、右边新写法。迁移时按"Agent → 记忆 → 流式 → 结构化输出 → RAG"顺序逐块替换即可。

### 3.1 示例一：创建 Agent（含工具）

**❌ Before（v0.x）**

```python
# 旧写法，仅作对照
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool


@tool
def search_web(query: str) -> str:
    """搜索互联网获取实时信息。"""
    return f"关于「{query}」的搜索结果……"


llm = ChatOpenAI(model="gpt-4o", temperature=0)
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个有用的助手。"),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),          # 旧执行器要求的占位符
])

agent = create_tool_calling_agent(llm, [search_web], prompt)
executor = AgentExecutor(agent=agent, tools=[search_web], verbose=True, max_iterations=5)
print(executor.invoke({"input": "AI Agent 最新进展"})["output"])
```

**✅ After（v1）**

```python
from langchain.agents import create_agent
from langchain.tools import tool


@tool
def search_web(query: str) -> str:
    """搜索互联网获取实时信息。"""
    return f"关于「{query}」的搜索结果……"


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_web],
    system_prompt="你是一个有用的助手。",
)
print(agent.invoke({"messages": [{"role": "user", "content": "AI Agent 最新进展"}]})["messages"][-1].content)
```

**要点**：① 执行器、`agent_scratchpad` 占位符、`max_iterations` 全部消失；② 循环由 `create_agent` 内置；③ 输入统一为 `{"messages": [...]}`。

### 3.2 示例二：记忆（多轮对话）

**❌ Before（v0.x）**

```python
# 旧写法，仅作对照
from langchain.memory import ConversationBufferMemory
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.tools import tool


@tool
def search_web(query: str) -> str:
    """搜索互联网。"""
    return "结果……"


memory = ConversationBufferMemory(memory_key="chat_history", return_messages=True)
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是助手。"),
    ("placeholder", "{chat_history}"),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])
llm = ChatOpenAI(model="gpt-4o")
executor = AgentExecutor(
    agent=create_tool_calling_agent(llm, [search_web], prompt),
    tools=[search_web],
    memory=memory,                                   # 内存记忆对象
)
executor.invoke({"input": "我叫小明"})
print(executor.invoke({"input": "我叫什么？"})["output"])
```

**✅ After（v1）**

```python
from langchain.agents import create_agent
from langchain.tools import tool
from langgraph.checkpoint.memory import InMemorySaver


@tool
def search_web(query: str) -> str:
    """搜索互联网。"""
    return "结果……"


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[search_web],
    system_prompt="你是助手。",
    checkpointer=InMemorySaver(),                    # 生产换 PostgresSaver
)
config = {"configurable": {"thread_id": "u1"}}       # 会话由 thread_id 标识

agent.invoke({"messages": [{"role": "user", "content": "我叫小明"}]}, config)
print(agent.invoke({"messages": [{"role": "user", "content": "我叫什么？"}]}, config)["messages"][-1].content)
```

**要点**：`ConversationBufferMemory` 及其变体**全部移除**；记忆 = checkpointer + `thread_id`；需要压缩时挂 `SummarizationMiddleware`。

### 3.3 示例三：流式输出

**❌ Before（v0.x）**

```python
# 旧写法，仅作对照：只拿到最终文本的逐块拼接
for chunk in executor.stream({"input": "讲个笑话"}):
    if "output" in chunk:
        print(chunk["output"], end="", flush=True)
```

**✅ After（v1）**

```python
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(model="openai:gpt-5.5", tools=[], checkpointer=InMemorySaver())
config = {"configurable": {"thread_id": "s1"}}

# ① messages 模式：逐 token（打字机效果）
for message_chunk, _meta in agent.stream(
    {"messages": [{"role": "user", "content": "讲个笑话"}]},
    config,
    stream_mode="messages",
):
    if message_chunk.content:
        print(message_chunk.content, end="", flush=True)

# ② updates 模式：逐节点更新（替代 return_intermediate_steps）
for step in agent.stream(
    {"messages": [{"role": "user", "content": "算 128*256"}]},
    config,
    stream_mode="updates",
):
    print(step)
```

**要点**：`stream_mode` 明确区分"逐 token"与"逐节点"；旧执行器那种"从 dict 里抠 `output` 字段"的写法彻底过时。

### 3.4 示例四：结构化输出

**❌ Before（v0.x）**

```python
# 旧写法，仅作对照：手工拼接 format_instructions 并解析
from pydantic import BaseModel, Field
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI


class WeatherReport(BaseModel):
    city: str = Field(description="城市")
    temperature: float = Field(description="温度")


parser = PydanticOutputParser(pydantic_object=WeatherReport)
prompt = ChatPromptTemplate.from_template(
    "从文本中抽取天气信息。\n{format_instructions}\n文本：{input}"
).partial(format_instructions=parser.get_format_instructions())

chain = prompt | ChatOpenAI(model="gpt-4o") | parser
print(chain.invoke({"input": "杭州今天晴天，25 度"}))
```

**✅ After（v1）**

```python
from pydantic import BaseModel, Field

from langchain.agents import create_agent


class WeatherReport(BaseModel):
    """天气报告。"""

    city: str = Field(description="城市")
    temperature: float = Field(description="温度（摄氏度）")
    condition: str = Field(description="天气状况")


agent = create_agent(
    model="openai:gpt-5.5",
    tools=[],
    response_format=WeatherReport,        # 自动选择 ProviderStrategy / ToolStrategy
)
result = agent.invoke({"messages": [{"role": "user", "content": "杭州今天晴天，25 度"}]})
report: WeatherReport = result["structured_response"]
print(report.city, report.temperature, report.condition)
```

**要点**：Agent 场景用 `response_format`（主循环内生成，无需额外一次调用）；纯 Chain 场景可保留 `llm.with_structured_output(Schema)`，但**不再需要** `PydanticOutputParser` + `format_instructions`。

### 3.5 示例五：RAG 检索链

**❌ Before（v0.x）**

```python
# 旧写法，仅作对照
from langchain_community.vectorstores import Chroma          # 旧路径
from langchain_community.embeddings import OpenAIEmbeddings  # 旧路径
from langchain_core.documents import Document
from langchain_openai import ChatOpenAI


embeddings = OpenAIEmbeddings(model="text-embedding-ada-002")
docs = [Document(page_content="RAG 缓解幻觉。", metadata={"source": "rag.md"})]
vectorstore = Chroma.from_documents(docs, embeddings, collection_name="kb")
vectorstore.persist()                                        # 已弃用
retriever = vectorstore.as_retriever()
```

**✅ After（v1）**

```python
from langchain_chroma import Chroma                          # 新路径
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings


embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
docs = [Document(page_content="RAG 缓解幻觉。", metadata={"source": "rag.md"})]

# 写入即落盘：只需指定 persist_directory，不要再调 persist()
vectorstore = Chroma.from_documents(
    documents=docs,
    embedding=embeddings,
    collection_name="kb",
    persist_directory="./chroma_db",
)
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})  # as_retriever 保留

# 下次启动直接加载已有集合
vectorstore = Chroma(
    collection_name="kb",
    embedding_function=embeddings,
    persist_directory="./chroma_db",
)
```

**要点**：① 向量库/嵌入模型迁到独立包；② `persist()` 删除；③ 完整的最小 RAG 闭环见[附录 B · 第 9 节](./02-速查卡.md)。

## 四、常见坑

| 坑 | 现象 | 正确做法 |
|:---|:-----|:---------|
| **`AgentExecutor` 不存在怎么办？** | `ImportError: cannot import name 'AgentExecutor'` | 用 `create_agent(model, tools, system_prompt=...)` 替代整套"agent + executor"；循环、记忆、流式全内置 |
| **`return_intermediate_steps` 的替代？** | 该参数报错，看不到中间步骤 | `agent.stream(..., stream_mode="updates")` 逐步打印；或接入 LangSmith / OTel 看 trace |
| **`MemorySaver` 路径变更** | `from langgraph.checkpoint import MemorySaver` 找不到 | 新路径：`from langgraph.checkpoint.memory import InMemorySaver` |
| **`langchain_community.vectorstores` 拆分** | `ModuleNotFoundError: langchain_community.vectorstores.Chroma` | 装独立包：`uv add langchain-chroma`，改用 `from langchain_chroma import Chroma`（FAISS/Qdrant 同理） |
| **`ConversationBufferMemory` 已移除** | ImportError | 改用 `checkpointer=InMemorySaver()` + `thread_id`；需要压缩挂 `SummarizationMiddleware` |
| **`max_iterations` 无效** | 传了参数但循环不终止 | 用 `ModelCallLimitMiddleware` / `ToolCallLimitMiddleware` |
| **追踪"打开了但没数据"** | 旧 `LANGCHAIN_TRACING_V2` 不再生效 | 改用 `LANGSMITH_TRACING` / `LANGSMITH_API_KEY` / `LANGSMITH_PROJECT` |
| **`langchain-classic` 缺失** | 旧 Chain/Retriever 导入失败 | 确认 `langchain` 收窄：需要的旧功能装 `langchain-classic`，或直接迁移到 v1 写法 |
| **`persist()` 报错** | `'Chroma' object has no attribute 'persist'` | 删除该调用，构造时传 `persist_directory` 即可 |
| **旧 prompt 里的 `agent_scratchpad`** | 占位符不再需要，传了反而报错 | 从 `ChatPromptTemplate` 中删除该 placeholder |

## 五、迁移 Checklist

> 逐项打勾。建议**按顺序**推进，每完成一组就跑一次最小用例验证。

**环境与依赖**

- [ ] `uv sync` 后确认 `langchain>=1.4.5`、`langchain-core>=1.6.10`、`langgraph>=1.2.15`
- [ ] 安装拆分后的集成包：`langchain-chroma`（及用到的 FAISS / Qdrant 包）
- [ ] 需要旧 Chain/Retriever 时补装 `langchain-classic`
- [ ] 环境变量前缀从 `LANGCHAIN_*` 改为 `LANGSMITH_*`

**Agent 与执行器**

- [ ] 删除 `AgentExecutor` / `create_tool_calling_agent` / `create_react_agent`，统一为 `create_agent`
- [ ] 删除 `agent_scratchpad` 占位符，提示词改用 `system_prompt=`
- [ ] `max_iterations` → `ModelCallLimitMiddleware`
- [ ] `return_intermediate_steps` → `stream(stream_mode="updates")`
- [ ] 输入统一为 `{"messages": [...]}`，输出取 `result["messages"][-1]`

**记忆**

- [ ] 删除 `ConversationBufferMemory` / `ConversationSummaryMemory` 等
- [ ] 加 `checkpointer=InMemorySaver()`（生产换 `PostgresSaver`）
- [ ] 会话隔离改用 `config={"configurable": {"thread_id": ...}}`
- [ ] 长对话加 `SummarizationMiddleware` 做压缩

**工具与输出**

- [ ] 导入路径统一到 `langchain.tools` / `langchain.messages`
- [ ] 工具异常改用 `ToolException` / `@wrap_tool_call`
- [ ] Agent 结构化输出改用 `response_format`，读取 `result["structured_response"]`

**RAG**

- [ ] 向量库导入改为独立包（`langchain_chroma` 等）
- [ ] 删除 `vectorstore.persist()`，改用 `persist_directory`
- [ ] 嵌入模型导入迁到 `langchain_openai` / `init_embeddings`
- [ ] 全流程统一嵌入模型与维度，必要时**重建索引**

**验证**

- [ ] 跑通一个最小 Agent（模型 + 1 工具 + 记忆）
- [ ] 跑通流式（`stream_mode="messages"`）
- [ ] 跑通结构化输出（`structured_response`）
- [ ] 跑通 RAG 最小闭环（加载 → 切分 → Chroma → 检索）
- [ ] 对照 [附录 C · 故障排查手册](./03-故障排查手册.md) 扫一遍报错清单
