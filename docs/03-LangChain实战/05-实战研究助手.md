## 📖 导读

前面我们学习了 LangChain 的各种组件——Chain、工具、向量存储、Agent。现在是时候**综合运用所有知识，构建一个真正实用的 Agent 应用**。

本节将带领你完成一个**研究助手 Agent**：它能接收一个研究主题，自动搜索资料、整理分析、生成结构化报告。这个项目涵盖 Agent 开发的完整流程，是后续构建复杂应用的基础。

> 🆕 **2026 版**：全部代码基于 **LangChain v1** 的 `create_agent` 编写（不再使用 `AgentExecutor`）。

---

## 一、项目需求

### 1.1 核心功能

创建一个研究助手，能够：

1. **搜索**互联网信息（获取原始资料）
2. **整理**和分析信息（提取关键点）
3. **生成**结构化研究报告（Markdown 格式）

### 1.2 用户视角

```text
用户输入：帮我研究一下 AI Agent 的发展趋势

Agent 输出：
# AI Agent 发展趋势研究报告

## 1. 核心发现
## 2. 关键数据
## 3. 技术分析
## 4. 结论与展望
```

## 三、逐步实现

### 3.1 完整代码（main.py）

```python
"""研究助手 - 单文件示例（LangChain v1）"""
import os
from datetime import datetime

from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.tools import tool

# 加载环境变量
load_dotenv()


# ===== 工具定义 =====

@tool
def search_web(query: str) -> str:
    """搜索互联网，获取与查询相关的最新资料。"""
    # 提示：实际项目应接入真实搜索 API（如 Tavily / Bing / SerpAPI）
    mock_results = {
        "AI Agent": (
            "1. AI Agent 市场规模持续高速增长\n"
            "2. 多 Agent 协作成为企业应用新趋势\n"
            "3. MCP 成为工具调用事实标准"
        ),
        "LangGraph": (
            "1. 基于图的工作流编排运行时\n"
            "2. 支持条件路由、循环、持久化与人机协同\n"
            "3. 与 LangChain v1 深度集成"
        ),
    }
    for key, result in mock_results.items():
        if key.lower() in query.lower():
            return result
    return f"关于'{query}'的搜索结果：\n1. 已找到相关工作\n2. 正在综合分析"


@tool
def save_report(content: str, filename: str = "") -> str:
    """把研究报告保存为 Markdown 文件，返回保存结果。"""
    if not filename:
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        filename = f"research_report_{timestamp}.md"
    with open(filename, "w", encoding="utf-8") as f:
        f.write(content)
    return f"✅ 报告已保存到 {filename}"


# ===== Agent 构建 =====

SYSTEM_PROMPT = """你是一个专业的研究助手。工作流程：
1. 理解研究主题，必要时拆解为子问题
2. 用 search_web 搜索资料
3. 综合分析后生成结构化 Markdown 报告（摘要/背景/发现/结论）
4. 用 save_report 保存最终报告
用中文撰写，结构清晰，标注信息来源。"""


def create_research_agent():
    """创建研究助手 Agent（LangChain v1）"""
    # 从环境变量读取 LLM 配置，便于跨厂商切换
    model = ChatOpenAI(
        model=os.getenv("LLM_MODEL_NAME", "gpt-5.5"),
        api_key=os.getenv("LLM_API_KEY"),
        base_url=os.getenv("LLM_BASE_URL"),
        temperature=0.3,  # 研究需要准确性，温度调低
    )
    # create_agent 内置"模型 → 工具 → 回传模型"的完整循环
    return create_agent(
        model=model,
        tools=[search_web, save_report],
        system_prompt=SYSTEM_PROMPT,
    )


# ===== 交互入口 =====

def main():
    """主函数"""
    print("🤖 AgentLearn - 研究助手")
    print("=" * 50)
    print("输入研究主题，我将为你生成研究报告（输入 exit 退出）\n")

    agent = create_research_agent()

    while True:
        try:
            topic = input("研究主题：").strip()
            if topic.lower() in ["exit", "quit", "q", "退出"]:
                print("👋 再见！")
                break
            if not topic:
                continue

            print("\n🔍 正在研究...\n")
            result = agent.invoke(
                {"messages": [{"role": "user", "content": f"请研究以下主题并生成报告：\n\n{topic}"}]}
            )
            print("=" * 50)
            print(result["messages"][-1].content)
            print("=" * 50)
            print()
        except KeyboardInterrupt:
            print("\n👋 再见！")
            break


if __name__ == "__main__":
    main()
```

下面按模块拆解这份代码。

### 3.2 工具定义

两个工具都用 `@tool` 装饰器定义，返回值统一为**字符串**，模型才能把结果回传给自己继续推理：

- `search_web(query)`：搜索资料（示例用模拟数据，真实项目可换 Tavily / Bing / SerpAPI）；
- `save_report(content, filename)`：把最终报告写入 Markdown 文件。

> 💡 工具的**描述（docstring）**会作为提示词提供给模型，直接影响它能否正确选择工具，所以务必写清楚"何时使用"。

### 3.3 Agent 构建（create_agent）

`create_agent` 一次性完成"模型 → 调用工具 → 回传结果 → 直到结束"的完整循环，无需 `AgentExecutor`：

```python
agent = create_agent(
    model=model,                       # 也可直接传模型名字符串
    tools=[search_web, save_report],
    system_prompt=SYSTEM_PROMPT,
)
```

其中 `model` 从环境变量 `LLM_*` 读取，便于在 OpenAI / Anthropic / DeepSeek 之间切换。

### 3.4 交互入口

`main()` 只做三件事：构建 Agent、读取用户主题、打印结果。真正的多步推理与工具调用全部交给 Agent 自主完成：

```python
agent = create_research_agent()

while True:
    topic = input("研究主题：").strip()
    if topic.lower() in ["exit", "quit", "q", "退出"]:
        break
    if not topic:
        continue

    result = agent.invoke(
        {"messages": [{"role": "user", "content": f"请研究以下主题并生成报告：\n\n{topic}"}]}
    )
    print(result["messages"][-1].content)
```

## 五、进阶优化

### 5.1 添加长期记忆（跨研究积累知识）

让 Agent 记住之前的研究成果。v1 推荐用 **LangGraph `store`** 或**向量库**：

```python
from langchain.agents import create_agent
from langgraph.store.memory import InMemoryStore
from langchain.tools import tool


store = InMemoryStore()


@tool
def recall_past_research(topic: str) -> str:
    """检索以往研究过的相关内容。"""
    items = store.search(("research",), query=topic, limit=3)
    if not items:
        return "没有找到相关历史研究。"
    return "\n\n".join(item.value["summary"] for item in items)


@tool
def save_research(topic: str, summary: str) -> str:
    """把本次研究的结论沉淀为长期记忆。"""
    store.put(("research",), topic, {"summary": summary})
    return "已保存到长期记忆。"


agent = create_agent(
    model="gpt-5.5",
    tools=[search_web, save_report, recall_past_research, save_research],
    system_prompt=SYSTEM_PROMPT,
    store=store,           # 跨会话长期记忆
)
```

> 📌 记忆的分层与持久化详见 [2.4 记忆机制](../02-核心概念/04-记忆机制.md)。

### 5.2 添加报告质量检查

```python
from langchain.chat_models import init_chat_model

checker_llm = init_chat_model("gpt-5.5", model_provider="openai", temperature=0)


class ResearchQualityChecker:
    """报告质量检查器"""

    def check_report(self, report: str, topic: str) -> str:
        prompt = f"""
        检查以下关于"{topic}"的研究报告的质量：

        报告内容：
        {report}

        请在以下维度打分（1-10）并给出改进建议：
        1. 完整性：是否覆盖了主题的主要方面
        2. 准确性：信息是否准确可信
        3. 结构性：报告结构是否清晰
        4. 可读性：语言是否流畅易懂
        5. 实用性：是否包含可操作的建议
        """
        return checker_llm.invoke(prompt).content
```

### 5.3 用 MCP 替换自建搜索工具

2026 年，搜索、网页读取等能力都可以直接通过 MCP Server 获得，无需自己维护：

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

client = MultiServerMCPClient({
    "web": {"url": "https://mcp.example.com/web", "transport": "streamable_http"},
})
tools = await client.get_tools()
agent = create_agent("gpt-5.5", tools=tools, system_prompt=SYSTEM_PROMPT)
```

## 六、扩展思路

| 扩展方向 | 实现方式 | 效果 |
|----------|----------|------|
| **接入真实搜索** | 集成 Tavily / Bing / SerpAPI | 获取真实互联网数据 |
| **多语言支持** | 增加语言参数控制 | 支持全球用户 |
| **图文报告** | 添加图片搜索和排版 | 更丰富的报告格式 |
| **协作研究** | 多 Agent 分工（搜索→分析→写作） | 更深入、更专业的报告 |
| **定期调研** | 加定时任务自动跟踪主题 | 持续性研究 |
| **可观测性** | 接入 LangSmith / Langfuse | 追踪每一步、便于调优 |

## 七、本章总结

| 要点 | 说明 |
|------|------|
| **单文件结构** | 工具 / Agent / 入口集中在 `main.py` |
