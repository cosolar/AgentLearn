## 📖 导读

> **RAG 的质量上限，取决于文档处理的质量。垃圾进，垃圾出。**

文档处理是 RAG 的第一步，也是最容易被忽视的关键环节。加载不完整、分块不合理、元数据丢失，都会直接拖垮检索效果。**好的文档处理能让 RAG 准确率提升 20–30%。** 本章除常规加载与分块外，重点补齐 **父子块（Parent-Child）** 与 **元数据设计**。

> 📌 本章依赖：`langchain-community`、`langchain-text-splitters`、`pypdf`、`python-docx`、`beautifulsoup4`。

```python
from langchain_community.document_loaders import DirectoryLoader, TextLoader

loader = DirectoryLoader(
```

### 2.4 文档清洗

```python
import re


def clean_document(doc):
    """清洗单个文档：去噪 + 记录清洗前后长度"""
    text = doc.page_content

    # 1. 合并多余空白
    text = re.sub(r"[ \t]+", " ", text)
    # 2. 压缩连续空行
    text = re.sub(r"\n{3,}", "\n\n", text)
    # 3. 去除常见页眉页脚噪声（按需定制）
    text = re.sub(r"^\s*第\s*\d+\s*页\s*$", "", text, flags=re.MULTILINE)

    doc.metadata["original_length"] = len(doc.page_content)
    doc.metadata["cleaned_length"] = len(text)
    doc.page_content = text.strip()
    return doc
```

## 三、文本分块（Chunking）

### 3.1 为什么需要分块？

```text
❌ 不分块的痛点：
1. 整篇文档太大，超过 LLM 的 context window
2. 太长 → Embedding 向量"平均化" → 检索精度下降
3. 一篇文档包含多个主题 → 检索命中率低

✅ 分块的好处：
1. 每块聚焦一个子主题 → 检索精度高
2. 长度可控 → 适合 Embedding 与 LLM 处理
3. 可识别具体引用来源（第几章第几节）
```

### 3.2 分块策略

```python
from langchain_text_splitters import (
    RecursiveCharacterTextSplitter,   # 递归字符分割（首选）
    TokenTextSplitter,                # Token 级别分割
    MarkdownHeaderTextSplitter,       # Markdown 标题分割
    PythonCodeTextSplitter,           # Python 代码分割
    CharacterTextSplitter,            # 简单字符分割
)
```

#### 策略一：RecursiveCharacterTextSplitter（首选）

**原理**：递归地尝试不同分隔符（`\n\n` → `\n` → `。` → 空格），尽量在自然边界处分割。

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,                                  # 每块最大字符数
    chunk_overlap=50,                                # 块间重叠字符数
    length_function=len,
    separators=["\n\n", "\n", "。", "！", "？", ".", " ", ""],
)

chunks = splitter.split_documents(docs)
print(f"分割为 {len(chunks)} 个块")
print(f"第 1 块（{len(chunks[0].page_content)} 字）: {chunks[0].page_content[:80]}...")
```

#### 策略二：TokenTextSplitter

按 Token 数分割，更贴合 Embedding 的 token 上限。

```python
from langchain_text_splitters import TokenTextSplitter

token_splitter = TokenTextSplitter(
    chunk_size=500,               # 每块 500 tokens
    chunk_overlap=50,
    encoding_name="cl100k_base",  # OpenAI 系列使用的编码
)
token_chunks = token_splitter.split_documents(docs)
```

#### 策略三：MarkdownHeaderTextSplitter

按标题层级分割，**保留章节结构**（标题会写入 metadata）。

```python
from langchain_text_splitters import MarkdownHeaderTextSplitter

markdown_splitter = MarkdownHeaderTextSplitter(
    headers_to_split_on=[("#", "h1"), ("##", "h2"), ("###", "h3")]
)

md_text = """# 第一章：Python 基础
## 1.1 变量
Python 是动态类型语言……
## 1.2 数据类型
常见类型包括整型、浮点型、字符串……
"""
chunks = markdown_splitter.split_text(md_text)
for chunk in chunks:
    print(chunk.metadata, "|", chunk.page_content[:30])
```

### 3.3 chunk_size 与 chunk_overlap 的选择

| chunk_size | 适用场景 | 优点 | 缺点 |
|-----------|----------|------|------|
| 128–256 | 代码、短文本 | 检索精度高 | 上下文不完整 |
| **500–1000** | **通用文档** | **平衡检索与生成** | **推荐** |
| 1000–2000 | 长段落、论文 | 上下文完整 | 检索精度下降 |

```text
没有重叠：
[...句子结尾...] [下一句开头...]
                ↑ 断开处可能丢失关键信息

有重叠：
[...句子结尾...重叠部分...]
                [重叠部分...下一句开头...]
                ↑ 上下文连贯性更好
```

**推荐配置**：`chunk_overlap = chunk_size 的 10% ~ 20%`。

## 四、父子块（Parent-Child Retrieval）

**痛点**：小块利于**检索精度**，大块利于**上下文完整**——二者矛盾。

**解法**：用**小块检索、用大块生成**。

- **父块（Parent）**：较大的语义单元（如一整节），用于喂给 LLM；
- **子块（Child）**：由父块切出的小块，用于建立向量索引；
- 命中子块后，**回溯其父块**作为上下文。

```python
"""父子块：小刀检索、大刀生成（手动实现，无额外依赖）"""
import uuid
from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter


def build_parent_child_chunks(
    docs: list[Document],
    parent_size: int = 2000,
    child_size: int = 400,
) -> tuple[list[Document], dict[str, Document]]:
    """
    返回：
      child_chunks —— 用于建向量索引（metadata 里带 parent_id）
      parent_store —— {parent_id: 父块 Document}，命中后回查
    """
    parent_splitter = RecursiveCharacterTextSplitter(
        chunk_size=parent_size, chunk_overlap=0,
        separators=["\n\n", "\n", "。", " ", ""],
    )
    child_splitter = RecursiveCharacterTextSplitter(
        chunk_size=child_size, chunk_overlap=child_size // 8,
        separators=["\n\n", "\n", "。", " ", ""],
    )

    child_chunks: list[Document] = []
    parent_store: dict[str, Document] = {}

    for doc in docs:
        for parent_text in parent_splitter.split_text(doc.page_content):
            parent_id = str(uuid.uuid4())
            parent_store[parent_id] = Document(
                page_content=parent_text, metadata=dict(doc.metadata)
            )
            for child_text in child_splitter.split_text(parent_text):
                child_chunks.append(
                    Document(
                        page_content=child_text,
                        metadata={**doc.metadata, "parent_id": parent_id},
                    )
                )

    print(f"父块 {len(parent_store)} 个 → 子块 {len(child_chunks)} 个")
    return child_chunks, parent_store


def retrieve_parents(vectorstore, parent_store, query: str, k: int = 3) -> list[Document]:
    """先用子块检索，再回溯父块作为上下文"""
    child_hits = vectorstore.similarity_search(query, k=k * 3)
    parent_ids, seen = [], set()
    for child in child_hits:
        pid = child.metadata.get("parent_id")
        if pid and pid not in seen:
            seen.add(pid)
            parent_ids.append(pid)
    return [parent_store[pid] for pid in parent_ids[:k]]
```

> 💡 **内置方案**：LangChain 提供 `ParentDocumentRetriever`（`from langchain.retrievers import ParentDocumentRetriever`）+ 一个 docstore（如 `from langchain.storage import InMemoryStore`），思路与上面完全一致，适合直接复用。

| 方案 | 检索粒度 | 生成上下文 | 适用 |
|------|----------|-----------|------|
| 单一分块 | 中等 | 中等 | 通用 |
| **父子块** | 小（准） | 大（全） | 长文档、法规、手册 |
| 句子窗口 | 句子 | 句子 + 前后窗口 | 精细问答 |

## 五、元数据设计（决定"能不能过滤、能不能溯源"）

分块后，`metadata` 是后续**过滤、溯源、增量更新**的基础。

```python
import hashlib


def enrich_metadata(chunks: list[Document], source_file: str) -> list[Document]:
    """为分块补齐统一元数据"""
    for i, chunk in enumerate(chunks):
        chunk.metadata.update({
            "source": source_file,                                   # 来源文件
            "chunk_index": i,                                        # 块序号
            "total_chunks": len(chunks),                             # 总块数
            "chunk_id": hashlib.md5(chunk.page_content.encode()).hexdigest(),  # 内容指纹（增量更新用）
        })
    return chunks
```

| 字段 | 作用 | 示例 |
|------|------|------|
| `source` | 溯源引用 | `"员工手册.pdf"` |
| `chunk_index` / `total_chunks` | 定位、拼接 | `3 / 42` |
| `chunk_id`（内容哈希） | 增量更新、去重 | `"a1b2c3..."` |
| `category` / `department` | 元数据过滤 | `"hr"` / `"legal"` |
| `access_level` / `roles` | 权限过滤（见 5.5） | `["hr", "admin"]` |
| `updated_at` | 时效性排序 | `"2026-01-01"` |

> ⚠️ 常见坑：分块后**忘记继承来源元数据**，导致检索到内容却不知道出处。务必在 split 后统一补齐 `source` 等字段。

## 六、实战：完整文档处理流水线

```python
"""文档处理流水线：加载 → 清洗 → 分块 → 元数据"""
import re
from pathlib import Path

from langchain_community.document_loaders import (
    DirectoryLoader, TextLoader, PyPDFLoader, Docx2txtLoader,
)
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.documents import Document


class DocumentProcessor:
    """多格式文档处理器"""

    LOADERS = {
        ".txt": (TextLoader, {"encoding": "utf-8"}),
        ".md": (TextLoader, {"encoding": "utf-8"}),
        ".py": (TextLoader, {"encoding": "utf-8"}),
        ".pdf": (PyPDFLoader, {}),
        ".docx": (Docx2txtLoader, {}),
    }

    def __init__(self, chunk_size: int = 500, chunk_overlap: int = 50):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap

    def load(self, path: str) -> list[Document]:
        p = Path(path)
        docs: list[Document] = []
        if p.is_file():
            loader_cls, kwargs = self.LOADERS[p.suffix.lower()]
            docs = loader_cls(str(p), **kwargs).load()
        else:
            for ext, (loader_cls, kwargs) in self.LOADERS.items():
                try:
                    loader = DirectoryLoader(
                        str(p), glob=f"**/*{ext}", loader_cls=loader_cls,
                        loader_kwargs=kwargs, show_progress=False,
                    )
                    docs.extend(loader.load())
                except Exception as e:  # noqa: BLE001
                    print(f"  ⚠️ 跳过 {ext}: {e}")
        for doc in docs:
            doc.metadata.setdefault("source", p.name)
        print(f"📂 加载 {len(docs)} 个文档")
        return docs

    def clean(self, docs: list[Document]) -> list[Document]:
        for doc in docs:
            text = re.sub(r"[ \t]+", " ", doc.page_content)
            text = re.sub(r"\n{3,}", "\n\n", text)
            doc.page_content = text.strip()
        return docs

    def split(self, docs: list[Document]) -> list[Document]:
        splitter = RecursiveCharacterTextSplitter(
            chunk_size=self.chunk_size,
            chunk_overlap=self.chunk_overlap,
            separators=["\n\n", "\n", "。", "！", "？", ".", " ", ""],
        )
        chunks = splitter.split_documents(docs)
        for i, chunk in enumerate(chunks):
            chunk.metadata["chunk_index"] = i
        print(f"✂️ 分割为 {len(chunks)} 个块")
        return chunks

    def process(self, path: str) -> list[Document]:
        return self.split(self.clean(self.load(path)))


if __name__ == "__main__":
    processor = DocumentProcessor(chunk_size=500, chunk_overlap=50)
    chunks = processor.process("./documents/")
    lengths = [len(c.page_content) for c in chunks] or [0]
    print(f"最短 {min(lengths)} / 最长 {max(lengths)} / 平均 {sum(lengths)//len(lengths)} 字符")
```

## 七、分块策略选择指南

| 文档类型 | 推荐策略 | chunk_size | 原因 |
|----------|----------|-----------|------|
| **技术文档** | MarkdownHeader | 500–1000 | 保留章节结构 |
| **小说/文章** | Recursive | 500–1000 | 自然段落边界 |
| **代码** | PythonCode | 200–500 | 函数级别分割 |
| **法律合同** | Recursive + 小 overlap | 300–500 | 精确度高要求 |
| **论文/报告** | Recursive + 大 overlap | 1000–2000 | 完整上下文 |
| **FAQ/问答** | 不分割（保持单条） | 按原样 | Q&A 对不宜拆分 |
| **长手册/法规** | **父子块** | 父 2000 / 子 400 | 兼顾精度与上下文 |

## 八、常见问题

### ❌ 分块破坏了关键信息

```python
# 问题：一句话被切成两段，检索时找不到
# 解决：增大 overlap + 在标点处分割
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=100,   # 增大重叠
    separators=["\n\n", "\n", "。", "！", "？", ".", "!", "?", " "],
)
```

### ❌ 元数据丢失

```python
# 问题：分块后不知道来源
# 解决：split 后统一补齐来源元数据
for i, chunk in enumerate(chunks):
    chunk.metadata["source"] = source_doc.metadata["source"]
    chunk.metadata["chunk_index"] = i
    chunk.metadata["total_chunks"] = len(chunks)
```

### ❌ 加载大文件超时

```python
# 问题：几百页 PDF 加载太慢
# 解决：只取需要的页
docs = PyPDFLoader("large.pdf").load()
```

## 九、本章小结

| 要点 | 说明 |
|------|------|
| **文档加载** | `DirectoryLoader` 批量加载多格式；中文指定 `encoding` |
| **文档清洗** | 去噪、标准化空白、去页眉页脚 |
| **文本分块** | `RecursiveCharacterTextSplitter`（首选） |
| **chunk_size** | 通用推荐 500–1000 |
| **chunk_overlap** | 推荐 size 的 10–20% |
| **父子块** | 小块检索、大块生成，兼顾精度与上下文 |
| **元数据** | 保留来源、序号、内容指纹、权限等，便于溯源与过滤 |
