# 5.3 向量数据库实战 —— 从 Chroma 到生产级部署

> 📅 更新至 2026-10 · 技术栈基线见 [教程大纲](../教程大纲.md)

## 📖 导读

> **向量数据库是 RAG 的"记忆库"。选型直接决定检索效率、维护成本与扩展能力。**

前面我们完成了文档处理，现在把"文档块"存入向量数据库并实现高效检索。本章覆盖 **Chroma（开发）→ FAISS（本地高性能）→ Qdrant（生产）→ Pinecone（全托管云）** 四条路径，并统一持久化口径，避免踩坑。

> 📌 与 [3.3 向量存储与检索](../03-LangChain实战/03-向量存储与检索.md) 保持一致：Chroma 用 `from langchain_chroma import Chroma`，**写入即落盘，禁止调用已弃用的 `vectorstore.persist()`**；Pinecone 使用新版 `Pinecone(api_key=...)` + `pc.Index(...)`。

## 二、向量数据库选型对比

| 数据库 | 部署方式 | 性能 | 易用性 | 成本 | 最佳场景 |
|--------|----------|------|--------|------|----------|

| **Pinecone** | 全托管云 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 按量付费 | 免运维生产 |
| **Milvus** | 自托管/云 | ⭐⭐⭐⭐⭐ | ⭐⭐ | 自建成本 | 企业级超大规模 |
| **Weaviate** | 自托管/云 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 按量付费 | 混合搜索需求 |

```text
开发阶段？
→ Chroma（零配置，快速上手）

本地/离线、追求性能？
→ FAISS（内存索引，极快）

生产环境、要自托管？
→ Qdrant（Rust 实现，本地/服务端两用）

生产环境、不想运维？
→ Pinecone（全托管）

海量数据（千万级+）？
→ Milvus / Elasticsearch（分布式）
```

## 三、Chroma 实战（开发首选）

### 3.1 安装

```bash
uv add langchain-chroma chromadb
```

### 3.2 基础操作

```python
from langchain_chroma import Chroma
from langchain_openai import OpenAIEmbeddings
from langchain_core.documents import Document

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

documents = [
    Document(page_content="AI Agent 是一种能够自主感知环境的智能系统。",
             metadata={"source": "doc1", "page": 1}),
    Document(page_content="LangChain 是一个构建 LLM 应用的框架。",
             metadata={"source": "doc2", "page": 2}),
]

# 方式一：从文档创建（写入即落盘）
vectorstore = Chroma.from_documents(
    documents=documents,
    embedding=embeddings,
    collection_name="agent_docs",
    persist_directory="./chroma_db",     # 指定后即自动持久化
)

# 方式二：加载已有集合（下次启动时）
vectorstore = Chroma(
    collection_name="agent_docs",
    embedding_function=embeddings,
    persist_directory="./chroma_db",
)

# 增量添加
vectorstore.add_documents([
    Document(page_content="向量数据库可将文本转为向量进行检索。",
             metadata={"source": "doc3", "page": 3}),
])

# ⚠️ langchain-chroma 在写入时已自动落盘到 persist_directory，
#    旧版 vectorstore.persist() 已弃用，无需（也不应）再调用。
```

### 3.3 检索操作

```python
# 1. 基础相似度搜索
results = vectorstore.similarity_search("什么是 AI Agent？", k=2)

# 2. 带相关性分数
scored = vectorstore.similarity_search_with_relevance_scores("什么是 AI Agent？", k=3)
for doc, score in scored:
    print(f"{score:.3f} → {doc.page_content[:30]}...")

# 3. 用向量直接搜索
query_vector = embeddings.embed_query("什么是 AI Agent？")
results = vectorstore.similarity_search_by_vector(query_vector, k=3)

# 4. MMR（最大边际相关性，兼顾相关性与多样性）
mmr = vectorstore.max_marginal_relevance_search(
    "什么是 AI Agent？", k=3, fetch_k=10, lambda_mult=0.5,   # 0=纯多样, 1=纯相关
)
```

### 3.4 高级功能

```python
# 1. 元数据过滤
filtered = vectorstore.similarity_search("AI Agent", k=3, filter={"source": "doc1"})

# 2. 复合过滤（Chroma 支持 $and / $or）
filtered = vectorstore.similarity_search(
    "AI Agent", k=3,
    filter={"$and": [{"source": {"$eq": "doc1"}}, {"page": {"$gte": 1}}]},
)

# 3. 更新 / 删除（按 id）
vectorstore.update_document(
    document_id="doc1",
    document=Document(page_content="更新后的内容", metadata={"source": "doc1"}),
)
vectorstore.delete(["doc1", "doc2"])

# 4. 集合信息
collection = vectorstore._collection
print(f"文档数: {collection.count()}  集合名: {collection.name}")
```

## 四、FAISS 实战（本地高性能）

FAISS 是 Meta 的向量检索库，索引常驻内存、速度极快，适合**本地/离线**场景。

```bash
uv add faiss-cpu        # CPU 版；GPU 版为 faiss-gpu（需 CUDA）
```

```python
# 注意：FAISS 未随 Chroma 一起拆分，仍在 langchain_community.vectorstores 中
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

vectorstore = FAISS.from_documents(documents, embeddings)

# 保存到本地
vectorstore.save_local("./faiss_index")

# 加载（v0.2+ 必须显式允许反序列化）
loaded = FAISS.load_local(
    "./faiss_index",
    embeddings,
    allow_dangerous_deserialization=True,
)
results = loaded.similarity_search("AI Agent", k=3)

# FAISS 特有：合并索引
db1 = FAISS.from_documents(docs1, embeddings)
db2 = FAISS.from_documents(docs2, embeddings)
db1.merge_from(db2)
```

> ⚠️ FAISS **不自动持久化**，必须手动 `save_local` / `load_local`；这与 Chroma"写入即落盘"不同。

## 五、Qdrant 实战（生产级自托管）

Qdrant 是 Rust 实现的高性能向量库，**既支持本地嵌入式（无服务），也支持服务端部署**，是 Chroma 到 Pinecone 之间的理想生产选项。

```bash
uv add langchain-qdrant qdrant-client
```

```python
from langchain_qdrant import QdrantVectorStore
from qdrant_client import QdrantClient
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 方式一：本地嵌入式（无需启动服务，数据存到本地目录）
client = QdrantClient(path="./qdrant_data")

# 方式二：连接服务端（docker run -p 6333:6333 qdrant/qdrant）
# client = QdrantClient(url="http://localhost:6333")
# client = QdrantClient(url="https://xxx.qdrant.io", api_key="your-key")  # 云端

vectorstore = QdrantVectorStore(
    client=client,
    collection_name="agent_docs",
    embedding=embeddings,
)

# 写入（本地模式下自动持久化到 path；服务端模式由服务负责持久化）
vectorstore.add_documents(documents)

# 检索（API 与 Chroma 基本一致）
results = vectorstore.similarity_search("AI Agent", k=3)

# 元数据过滤（Qdrant 使用 Filter 对象，比字典过滤更结构化）
from qdrant_client import models

results = vectorstore.similarity_search(
    "AI Agent", k=3,
    filter=models.Filter(
        must=[models.FieldCondition(key="metadata.source", match=models.MatchValue(value="doc1"))]
    ),
)
```

| 部署形态 | 客户端 | 持久化 |
|----------|--------|--------|
| 本地嵌入式 | `QdrantClient(path=...)` | 自动写入本地目录 |
| 自托管服务 | `QdrantClient(url="http://localhost:6333")` | 由 Qdrant 服务管理 |
| Qdrant Cloud | `QdrantClient(url=..., api_key=...)` | 由云端管理 |

## 六、Pinecone（全托管云）

```bash
# 包名已由 pinecone-client 更名为 pinecone（v5+）
uv add pinecone langchain-pinecone
```

```python
from pinecone import Pinecone, ServerlessSpec
from langchain_pinecone import PineconeVectorStore
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 1. 新版客户端（取代旧的 pinecone.init()）
pc = Pinecone(api_key="your-api-key")

# 2. 创建索引（只需一次）
index_name = "agent-guide"
if index_name not in pc.list_indexes().names():
    pc.create_index(
        name=index_name,
        dimension=1536,                    # text-embedding-3-small 维度
        metric="cosine",
        spec=ServerlessSpec(cloud="aws", region="us-east-1"),
    )

# 3. 获取索引句柄（取代旧的全局索引管理）
index = pc.Index(index_name)

# 4. 构建向量存储（直接传入索引对象）
vectorstore = PineconeVectorStore(index=index, embedding=embeddings)

vectorstore.add_documents(documents)
results = vectorstore.similarity_search("AI Agent", k=3)
```

## 七、持久化口径对照（重点，避免踩坑）

| 数据库 | 写入后如何持久化 | 加载已有数据 | 注意事项 |
|--------|------------------|--------------|----------|
| **Chroma** | 指定 `persist_directory` 后**自动落盘** | `Chroma(..., persist_directory=...)` | ❌ **不要**调用 `vectorstore.persist()`（已弃用） |
| **FAISS** | 手动 `save_local(path)` | `FAISS.load_local(path, embeddings, allow_dangerous_deserialization=True)` | 不自动保存 |
| **Qdrant（本地）** | 自动写入 `path` 目录 | `QdrantClient(path=...)` | 同一目录不能被多进程同时占用 |
| **Qdrant（服务）** | 由服务端持久化 | `QdrantClient(url=...)` | 需部署 Qdrant 服务 |
| **Pinecone** | 云端自动 | `pc.Index(name)` | 按量计费 |

## 八、构建完整的 RAG 检索系统

```python
"""基于 Chroma 的完整 RAG 问答系统"""
import os

from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_chroma import Chroma
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough


def get_llm() -> ChatOpenAI:
    return ChatOpenAI(
        model=os.getenv("LLM_MODEL_NAME", "gpt-5.5"),
        api_key=os.getenv("LLM_API_KEY"),
        base_url=os.getenv("LLM_BASE_URL"),
        temperature=0,
    )


class RAGSystem:
    """完整 RAG 检索问答系统"""

    def __init__(self, persist_dir: str = "./chroma_db"):
        self.embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
        self.vectorstore = Chroma(
            collection_name="rag_system",
            embedding_function=self.embeddings,
            persist_directory=persist_dir,      # 写入即落盘
        )
        self.retriever = self.vectorstore.as_retriever(
            search_type="similarity",
            search_kwargs={"k": 4, "score_threshold": 0.3},
        )
        self.chain = self._build_chain()

    def _build_chain(self):
        template = (
            "你是知识库问答助手。只基于参考信息回答；\n"
            "若参考信息没有相关内容，回答'未找到相关信息'；\n"
            "回答时标注来源文件名。\n\n"
            "参考信息：\n{context}\n\n问题：{question}\n\n回答："
        )

        def format_docs(docs: list[Document]) -> str:
            return "\n\n".join(
                f"[来源: {d.metadata.get('source', '未知')}]\n{d.page_content}" for d in docs
            )

        return (
            {"context": self.retriever | format_docs, "question": RunnablePassthrough()}
            | ChatPromptTemplate.from_template(template)
            | get_llm()
            | StrOutputParser()
        )

    def add_documents(self, documents: list[Document]) -> None:
        self.vectorstore.add_documents(documents)   # 自动持久化，无需 persist()
        print(f"✅ 已添加 {len(documents)} 个文档")

    def query(self, question: str) -> str:
        return self.chain.invoke(question)

    def query_with_sources(self, question: str) -> dict:
        docs = self.retriever.invoke(question)
        return {
            "question": question,
            "answer": self.chain.invoke(question),
            "sources": [d.metadata.get("source", "未知") for d in docs],
        }


if __name__ == "__main__":
    rag = RAGSystem()
    rag.add_documents([
        Document(page_content="AI Agent 的核心能力包括感知、推理、行动和记忆。",
                 metadata={"source": "agent_intro.md"}),
        Document(page_content="RAG 是检索增强生成的缩写，用于提升 LLM 回答质量。",
                 metadata={"source": "rag_intro.md"}),
    ])
    result = rag.query_with_sources("什么是 AI Agent？")
    print(f"Q: {result['question']}\nA: {result['answer']}")
    print("来源:", result["sources"])
```

## 九、性能优化技巧

```python
# 1. 批量写入（避免一次性传入海量文档）
def batch_add(vectorstore, docs, batch_size: int = 100) -> None:
    for i in range(0, len(docs), batch_size):
        vectorstore.add_documents(docs[i:i + batch_size])
        print(f"  已写入 {min(i + batch_size, len(docs))}/{len(docs)}")

# 2. 异步检索
async def async_search(vectorstore, query: str):
    return await vectorstore.asimilarity_search(query, k=3)

# 3. 限制检索范围（元数据过滤）
def category_retriever(vectorstore, category: str):
    return vectorstore.as_retriever(
        search_kwargs={"k": 3, "filter": {"category": category}}
    )

# 4. 降维节省存储（OpenAI 特有，可指定输出维度）
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small", dimensions=256)
```

## 十、常见问题

### ❌ 误用 `vectorstore.persist()`

```python
# ❌ 旧写法（已弃用，langchain-chroma 中会报错或警告）
# vectorstore.persist()

# ✅ 新写法：只要指定了 persist_directory，写入即自动落盘
vectorstore = Chroma.from_documents(
    documents=docs, embedding=embeddings,
    collection_name="kb", persist_directory="./chroma_db",
)
```

### ❌ 跨会话数据丢失（Chroma 未指定持久化目录）

```python
# 原因：未指定 persist_directory → 内存模式，重启即丢
# ✅ 解决：始终指定 persist_directory
vectorstore = Chroma.from_documents(
    documents=docs, embedding=embeddings,
    collection_name="kb", persist_directory="./persistent_db",
)
```

### ❌ 检索结果为空

```python
# 原因：查询与文档语义差异大，或阈值过高
# 解决：降低 score_threshold；改用查询扩展 / 混合检索（见 5.4）
retriever = vectorstore.as_retriever(
    search_kwargs={"k": 5, "score_threshold": 0.2}
)
```

## 十一、本章小结

| 概念 | 说明 |
|------|------|
| **Chroma** | 开发首选，零配置；指定 `persist_directory` 即自动持久化，**不用 `persist()`** |
| **FAISS** | 本地高性能，需手动 `save_local` / `load_local` |
| **Qdrant** | 生产级，本地嵌入式与服务端两用，过滤用 `Filter` 对象 |
| **Pinecone** | 全托管云，用新版 `Pinecone(api_key=...)` + `pc.Index(...)` |
| **检索参数** | `k`（数量）、`score_threshold`（质量）、`filter`（过滤） |
| **优化** | 批量写入、异步检索、降维、元数据过滤 |
