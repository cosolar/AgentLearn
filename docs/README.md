## 🚀 先跑起来：5 分钟见到第一个 Agent

> 这一步**不需要读任何理论**。先让它在你的机器上说话，再回头理解为什么。

```bash
# 1. 准备：Python 3.12+ 与 uv（https://docs.astral.sh/uv/）
git clone https://gitcode.com/mininote/AgentLearn.git
cd AgentLearn

# 2. 装依赖 + 配密钥
uv sync
cp .env.example .env          # 编辑 .env，填入 LLM_API_KEY

# 3. 跑第一个 Agent
python examples/01-hello-agent/main.py
```

**没有 API Key？** 这三个示例用脚本化假模型跑完整链路，零联网、零密钥：

```bash
cd examples/09-mini-harness && python smoke_test.py   # 19 项断言
cd examples/05-rag-kb      && python smoke_test.py   # 18 项断言
cd examples/07-api-service && python smoke_test.py   # 16 项断言
```

跑通之后，从 [1.1 AI Agent 导论](01-入门基础/01-AI-Agent导论.md) 正式开始。

## 🎯 这份教程解决什么问题

| 维度 | 常见教程 | **AgentLearn** |
|:--|:--|:--|
| **覆盖面** | 只讲框架用法 | 框架 + 协议 + 生态 + **Harness 工程** |
| **时效性** | 停留在 2023–2024 的 API | 对齐 **2026 年 10 月** 技术栈（`create_agent`、MCP、AGENTS.md） |
| **深度** | 到"能跑起来"为止 | 一直讲到**生产就绪**：权限、验证循环、可观测性 |
| **代码** | 片段式、复制跑不通 | **9 个完整可运行示例 + 离线自检**，无需 API Key |

核心判断只有一句：

> **Agent = Model + Harness** —— 模型是商品，Harness 是护城河。

## 📖 怎么读一章（建议照做）

| 步骤 | 做什么 | 为什么 |
|:-:|:--|:--|
| **① 读导读** | 先看开头的「一句话结论 + 前置阅读 + 你将学到」 | 90 秒判断这章要不要现在读 |

## 💻 运行文档网站

> ⚠️ **必须通过 HTTP 服务器访问**（docsify 需要 fetch 加载 md，直接双击 `index.html`（`file://`）会空白）。

```bash
# 方式一：docsify-cli（推荐）
npx docsify-cli serve docs
#   ⚠️ 注意：是 docsify-cli，不是 docsify。
#       npm 上的 `docsify` 包没有命令行入口，`npx docsify serve` 会报
#       "could not determine executable to run"。
#   ⚠️ docsify-cli 要求 Node >= 20.11
# 访问 http://localhost:3000

# 方式二：任意静态服务器（在 docs 目录下启动，使其成为网站根目录）
cd docs
python -m http.server 3000
# 访问 http://localhost:3000

# 方式三：全局安装
npm i -g docsify-cli
docsify serve docs
```

> 💡 **部署路径说明**：`docs/index.html` 中**不要写死 `basePath: '/'`**。留空时 docsify 以 `index.html` 所在目录为基准解析 `README.md` / `_sidebar.md`，因此无论访问 `/`、`/docs/` 还是子路径都能正常加载；写死 `/` 会导致在非站点根目录下 `README/_sidebar` 404（页面空白）。
